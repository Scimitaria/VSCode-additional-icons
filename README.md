# VSCode Additional Icons
Adding some icons to VSCode for more obscure languages

Install by running `build.zsh`

### Languages Supported
| Language     | File Extensions |
| ---          | ---             |
| APL          | .apl            |
| AppleScript  | .applescript    |
| ActionScript | .as, .fla       |
| Awk          | .awk            |
| Binary       | .bin            |
| COBOL        | .cbl, .cobol    |
| Hexadecimal  | .hex            |
| HolyC        | .HC, .HH        |
| MIPS         | .mips           |
| SQL          | .sql            |
| VimScript    | .vim            |
| Visual Basic | .vb, .vba       |
